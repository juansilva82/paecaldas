# paecaldas.co · Plataforma Departamental de Consolidación del PAE

Caldas, Reconstruir es Avanzar. Los 27 municipios reportan necesidades (N-), intervenciones (I-) y proyectos (P-) para la Cartera Única del Plan de Acción Específico tras el sismo del 10 de agosto de 2026.

- `index.html` — la plataforma (consolidado público, espacio municipal, panel de la Gobernación).
- `catalogo.js` — ejes, 17 líneas del PAE con su dimensionamiento, municipios, listas y taxonomía nacional.
- `xlsx.js` — lectura y escritura de Excel sin dependencias.
- `config.js` — URL de la base de datos (Google Apps Script).

Publicación: Vercel despliega cada cambio en `main`. El código de la base de datos (Apps Script) se mantiene fuera de este repositorio.
